# Two-minute demo: DealSignal Radar

Run `streamlit run app.py` and open at 1440×900, zoom 100%. Keep the default filters. **Northmere Components is selected automatically even though it is rank #5.** All companies and evidence are fictional; no API key is needed.

**0:00–0:20 — Frame the early-warning question**

“This asks which private companies show evidence of entering a material transaction in the next twelve months. Fourteen deliberately constructed scenarios test the behaviour. The validation path is a 100-company shadow pilot, then a 100k universe—not a claim that either has already been built.”

**0:20–0:50 — Lead with Emerging, not an obvious sale process**

Point to Northmere. “There is no public transaction process identified. Mature sponsor ownership, a CFO appointment, board changes, a security filing, expansion and sector consolidation create an Emerging warning. These are independent readiness clues. The unchanged rules produce a propensity index of 54.5, evidence confidence of 91.5, and analyst review. Its honest rank remains fifth.”

“Both values are 0–100 indices, not probabilities. Evidence confidence measures source reliability, not statistical model confidence.”

**0:50–1:15 — Trace the evidence**

Open **Evidence explorer**. “The stage rule and contributing events are visible. Every record retains its source family, dates, supporting text and multipliers. The sources here are fictional, so no URLs are invented.” Expand the latest board-change record and briefly show **Score calculation**.

**1:15–1:35 — Contrast precision with lead time**

Select **Alderwick Systems**. “Explicit strategic-review and sale reporting make this Process-confirmed. That may improve precision, but it may arrive too late to give research teams an advantage. The test is whether earlier signal combinations produce useful lift and lead time.”

Optional alternative: Vesper demonstrates elevated propensity with low evidence confidence; four copies still count as one event.

**1:35–2:00 — Separate forecasting from commercial action**

Open **Methodology & scale**. “Forecasting and deploying scarce research capacity are different decisions. Today's queue uses a transparent prototype heuristic. Production would add an evidence-quality gate, client demand, coverage gaps/freshness and capacity. Those commercial inputs are not implemented. Historical point-in-time testing and later research consumption decide whether this is useful.”
